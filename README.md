# Eigo Taxi Link (英語教室 送迎チケット管理システム)

個人で英語教室を運営されている先生のための、**送迎サービス回数券（チケット）管理 ＆ スケジュール自動連携 Web アプリケーション**です。

---

## 🌟 主な機能・特徴

### 1. 先生向け機能（PC・スマホ両対応）
- **本日の送迎タイムライン**:
  - 今日の送迎スケジュール（お迎え/送り/往復、時間、場所、Googleマップリンク）を一覧表示
  - **「送迎完了（1回消費）」ボタン** をワンタップするだけで、チケット残数が自動でマイナス1されます。
- **送迎スケジュール管理**:
  - 前もって決まっている定期予定も、前日・当日に急遽入ったスポットの送迎も即時登録可能
- **生徒台帳 ＆ チケット残数管理**:
  - 生徒ごとの現在残チケット数をリアルタイム表示
  - 残少（残り1回）や残ゼロの生徒を視覚的にハイライト警告
  - **「チケット追加」機能**（5回券・10回券などのプリセット追加、受取金額・メモの履歴管理）
  - 新規生徒の登録（お迎え場所・住所、保護者緊急連絡先、送迎時のメモ）

### 2. 生徒・保護者向けポータル（スマホ最適化）
- **チケット残数のリアルタイム確認**:
  - 「現在のチケット残数：残り 7 回」と分かりやすく表示
- **送迎の予約登録（前日・当日対応）**:
  - 希望日時、送迎区分（お迎え/送り/往復）、送迎場所、連絡メモを入力して送信
  - 予約時点ではチケットは引かれず、**先生が送迎完了した時に消化されるため安心**
- **ワンタップキャンセル**:
  - 都合が悪くなった場合、予約一覧からワンタップでキャンセル可能
  - キャンセルと同時に**先生のGoogleカレンダーからも予定が自動削除**されます。

### 3. Google連携（維持費ゼロ・完全無料）
- **Googleスプレッドシート（データベース）**:
  - `生徒台帳`、`送迎予定履歴`、`チケット購入履歴` の3つのシートで安全・透明にデータを一元管理
- **Googleカレンダー（自動同期）**:
  - 予約が入ると自動で先生のGoogleカレンダーに予定を作成
  - キャンセルされると自動でカレンダーから削除

## 🚀 ローカルでの動作確認

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

起動後、ブラウザで `http://localhost:5173` を開くと、モックデータが入った状態で全機能（予約・キャンセル・送迎完了・チケット追加）をすぐにお試しいただけます。

## 🔗 Google スプレッドシート ＆ カレンダーの連携手順

1. [Google スプレッドシート](https://sheets.new) を新規作成します。
2. 上部メニューの **「拡張機能」 > 「Apps Script」** を開きます。
3. `gas/Code.gs` の内容をすべて貼り付けて保存します。
4. エディタ上部の関数プルダウンから **`initSpreadsheet`** を選択して「実行」をクリックします（初回に必要なシートが自動生成されます）。
5. 画面右上の **「デプロイ」 > 「新しいデプロイ」** をクリックします。
   - 種類の選択: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 発行された **「ウェブアプリの URL」** をコピーし、アプリ内の **「Google連携」タブ** に貼り付けて保存すれば、本番連携が完了します。
