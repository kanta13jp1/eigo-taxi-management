## 使う人の操作

1. 管理者は管理者専用URL、生徒・保護者は本人用の家庭別URL／QRを開きます。

3. 管理者には管理画面だけを、利用者には登録済みのお子様の残数・予約・取消・履歴だけを表示します。

利用者は教室のGAS接続先URLや長いアクセスキーを入力しません。Googleへの再ログインが必要な場合はGoogleの画面で本人確認します。教室・開発者が本人のGoogleパスワードを受け取る運用にはしません。

## 開発者が設定するもの

| 設定 | 担当と扱い |
| --- | --- |
| GAS接続先 | 開発者が配布版に設定。通常の利用画面には入力・変更欄を置かない |
| Google認証 | 開発者が対象Firebaseプロジェクト、認証方式、許可ドメインを設定 |
| 本人と役割 | 初期管理者を開発者が設定し、日常の本人登録・役割設定は管理者画面で実施 |
| お子様の紐付け | 管理者画面で対象生徒を選択。生徒作成だけでは保護者権限を自動付与しない |
| 個別URL・QR | 家庭のランダムIDを登録して配布。本人確認の秘密値をURLやQRに含めない |
| 退会・担当変更 | サーバーの許可設定を失効・変更し、次の利用時にも権限を再確認 |

管理者と保護者の画面分離は維持します。URLを知っているだけでは使えません。未登録のGoogleアカウントに権限を自動付与せず、他家庭のURLを開いてもデータを見せません。
