仕様正本は [ポータル分離仕様](../../PORTAL_SEPARATION.md)。検証用サイトは [管理者入口](https://eigo-taxi-test.web.app/#/admin) と管理者が家庭別に取得するURLを使用します。GASは同じ接続先のv2、テストWebは配信ファイル一致を確認済み。本人専用キーは資料・URL・QRに含めません。

GAS自動回帰42件、フロント契約回帰9件、実API参照11件が合格。実接続の管理者・家庭ページ、2家庭のQR切替、URLコピー、PNGからのURL復号を確認しました。端末側へのファイル保存完了とスマホカメラでの読取は未確認です。[今回の証跡](../../acceptance/role-portals-2026-10-20/) を参照してください。

AT-23の既存PASSを維持し、AT-24〜30の7件は未合格です。Calendar権限は未付与。本番運用は教室側アカウント・受入・責任者確認が必要です。検証台帳と元台帳は別で自動同期せず、直接編集後はF5等で再取得します。

5冊65ページを描画し全ページを目視確認しました。パッケージ、レイアウト、フォント、枚数、Artifact Tool再インポートも検証しています。PowerPointアプリでの実表示は未確認です。画面例はローカルの架空データであり、実家庭の情報を含みません。

過去のv3〜v9、143ページの旧受入資料、当時の証跡・報告は履歴として保存しています。旧画面のタブ切替手順にはv10と現行仕様が優先します。元ファイルを今回の合格証跡へ書き換えていません。Driveアップロード・外部送信・本番公開は行っていません。
