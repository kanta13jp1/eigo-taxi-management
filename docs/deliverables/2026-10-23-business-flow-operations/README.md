# 現場の送迎業務を追加したビジネスフロー

[最新版PowerPoint（11枚）](business-flow-operations-2026-10-23-v1.pptx)

ユーザー指摘により、前版のレビューがシステム機能中心で「カレンダー確認から実送迎」までを独立して表現していなかったことを修正。
11枚目に「当日の予定確認・実送迎・チケット消費」を追加し、2枚目から参照。

先生・送迎担当がカレンダーと予約一覧で時刻・生徒・場所・取消変更を確認し、実際に迎え／送りを実施。乗車・到着と実施結果を確認後、管理者が完了登録し、片道1枚・往復2枚を消費。保護者は残数と利用履歴を確認。

未実施・取消は完了にしない。カレンダー閲覧や実際の移動だけでは自動消費せず、完了登録が必要。残数不足は2・3枚目の追加フローへ。往復の片道だけ実施・無断欠席・返金等の規定は教室と確定する。
Calendar権限追加・実連携受入・本番運用開始を実施したものではない。
構造・配置・フォント・再取込検証通過。変更した2枚目と追加11枚目を描画確認。他9枚は前版の確認済み内容を維持。

元のレビュー結果は履歴として保持するが、「全業務を漏れなく確認済み」とは扱わない。
