## PROGRESS-20261110-AT28MS-02　ソースから確認した事実

| 確認ID | 事実 | 根拠 |
| --- | --- | --- |
| AT28MS-S01 | GASはシートを**名前だけ**で取得する。対象は「生徒台帳」「送迎予定履歴」「チケット購入履歴」の3つ。 | `sheet_()` の `getSheetByName(name)`、`initSpreadsheet()` |
| AT28MS-S02 | シートID（gid）、名前付き範囲、保護のAPIはGASから使っていない。 | `getSheetId`・`getRangeByName`・`NamedRange`・`protect`・`getProtections` を検索し該当なし |
| AT28MS-S03 | GASは紐付いたスプレッドシート（`getActiveSpreadsheet()`）だけを読む。別ファイルをIDで開く処理はない。 | `openById` を検索し該当なし |
| AT28MS-S04 | 検証担当モードはスプレッドシートのファイルIDと `ACCEPTANCE_REVIEW_SPREADSHEET_ID` の一致を条件にしている。 | `reviewModeAvailable_()` |
| AT28MS-S05 | 必要なシートが名前で見つからない場合は `NOT_INITIALIZED` で拒否する。模擬試験は「送迎予定履歴」を消した状態の `getRides` を確認している。他のシート・他の操作での同じ拒否は今回個別に確認していない。 | `sheet_()`、[模擬試験](../../scripts/test_gas.cjs) |

## PROGRESS-20261110-AT28MS-03　復元方式への影響（ソースからの推論。Google上では未観測）

- **ファイルごと差し替える方式**は、ファイルIDが変わる。S03・S04から、公開中のWebアプリは元のファイルを読み続け、検証担当モードの条件も新しいファイルでは一致しないと考えられる。台帳の中身を元のファイルへ戻す方式を基本とする。
- **シート単位の複写**は、11月6日の観測で新しいgidと「〜 のコピー」という名前になった。S01から、複写したシートを正規の名前へ変更するまでGASはそのシートを読まない。同名のシートは同時に置けないので、旧シートの退避・改名と新シートの改名の間はS05の拒否になる見込み。この間は利用者の操作を止める必要がある。
- S02から、gidの変更はGASに影響しない見込み。gid付きで保存したリンク（資料・共有表）は別途確認が必要。
- 実台帳に他シートを参照する数式があるかは未確認。11月5日の照合範囲（主要3シートの先頭8行）に数式セルはなかった。

## PROGRESS-20261110-AT28MS-04　次の試験の比較項目（すべてNOT_RUN）

対象は11月6日の[架空復元先](https://docs.google.com/spreadsheets/d/1Z9fcMWKxZhwPhPpQA6uKCan-tnZHmSNwf91tk70WY74/edit)と[架空バックアップ](https://docs.google.com/spreadsheets/d/15GPT2td_XqGEdg63IRjK1qDfU_fzDuyPXrAA-59xITA/edit)をそれぞれ「コピーを作成」した新しい架空ファイルだけ。元の2ファイル、実台帳、検証台帳、顧客確認用データは変更しない。

準備：架空の「データ」シート（B2=10）と「集計」シート（A2=`='データ'!B2*2`）を作る。「データ」!B2へ名前付き範囲、「データ」のA1:B2へ範囲の保護、「集計」へシートの保護、1行目の固定、フィルタを設定し、この状態をバックアップへ複写する。復元先では「データ」!B2を99へ変え、名前付き範囲・保護・固定・フィルタを外す。

| 比較ID | 操作 | 読み取る内容 |
| --- | --- | --- |
| AT28MS-C01 | バックアップの「データ」!A1:B2を復元先へ通常貼り付け | 「集計」!A2の数式文字列と計算結果 |
| AT28MS-C02 | 同上 | 名前付き範囲・範囲の保護・固定・フィルタが戻るか（各設定パネルで確認） |
| AT28MS-C03 | バックアップの「データ」をシート単位で復元先へ複写 | 複写後のシート名とgid。「集計」!A2がどちらの「データ」を参照しているか |
| AT28MS-C04 | 旧「データ」を「データ_旧」へ改名し、複写したシートを「データ」へ改名 | 「集計」!A2の数式文字列が改名に追従して「データ_旧」を指すか、新しい「データ」を指すか |
| AT28MS-C05 | 「データ_旧」を削除 | 「集計」!A2が `#REF!` になるか、値を保つか |
| AT28MS-C06 | バックアップの「データ」「集計」の両方をシート単位で複写 | 複写した「集計」の数式が、復元先の既存シートと複写したシートのどちらを参照するか |

各項目は数式バー・設定パネルの読み取り値と画像を保存し、見た目だけで復元済みと判定しない。結果は架空ファイルでの1回の観測として記録し、実台帳への適用やAT-28合格の根拠にはしない。C04・C05の結果で、実台帳に使う手順（範囲貼り付け＋不足設定の補正か、シート複写＋改名か）と、数式の参照先を照合する手順を決める。
