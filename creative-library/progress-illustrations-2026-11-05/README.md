# 送迎管理・進捗資料用イラスト

2026-11-05に、一般向けのPowerPointを分かりやすくするため、画像生成ツールで作成した架空の説明用イラストです。MightyLINKの青・オレンジを参考にした色で、実在の人物・教室・車両や実画面の写真ではありません。

- `teacher-parent-child.png`：先生・保護者・生徒とスマートフォン。
- `transport-phone.png`：送迎車・スマートフォン・予約のイメージ。
- `ledger-backup.png`：台帳とバックアップを照合するイメージ。
- `flat-teacher-family.png`：見本の青・オレンジを参考にした、先生と家庭のフラットなイラスト。
- `flat-ledger-comparison.png`：見本を参考にした、2枚の台帳と虫眼鏡のイラスト。
- `flat-phone-check.png`：画面が無地のスマートフォンとチェックマークのイラスト。地図や位置追跡の表現はありません。

画像はすべて1536×1024ピクセルのRGBA PNGです。図中の車種・乗車人数・画面デザインなどは架空の表現であり、実際の運用仕様や検証結果の証拠として扱いません。PowerPointで使用する際はイメージ画像として明示します。

画像生成の原本はCodexの生成画像領域に保持し、ここには元ファイルをコピーしています。ほかへの公開は行っていません。
